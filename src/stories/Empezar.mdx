# @pese-cl/ui

Librería de componentes de **PESE** (Peña y Sepúlveda): software que encaja con tu negocio.

Son componentes de React **sin estado y listos para SSR**: sirven en Astro, Next.js o Remix sin enviar JavaScript extra al navegador. Cumplen accesibilidad AAA y cambian solos entre tema claro y oscuro.

## Instalación

```bash
npm install @pese-cl/ui
```

## Primer uso

```tsx
import { Button } from '@pese-cl/ui';
import '@pese-cl/ui/styles.css';

export default function Page() {
  return (
    <div className="pese-root">
      <Button href="/diagnostico-gratuito">Pedir diagnóstico</Button>
    </div>
  );
}
```

Envuelve tu app en un contenedor con la clase `pese-root`: le da el fondo, la tipografía y el foco de la marca.

## Cómo leer esta documentación

Cada pieza tiene su página con **para qué sirve**, **cuándo usarlo**, la tabla de propiedades y varios casos de uso. Debajo de cada caso, el botón **Show code** muestra el código listo para copiar.

La librería sigue el **diseño atómico**: piezas pequeñas que se combinan en piezas más grandes.

- **Marca:** logo e iconos.
- **Átomos:** las piezas más pequeñas, que no se pueden dividir: botón, enlace, etiqueta de campo, título, texto, sobretítulo, imagen, separador, indicador de carga, etiqueta y estado, indicador de niveles, y la ayuda y el error de un campo.
- **Moléculas:** átomos combinados para una tarea: campo de texto, área de texto, lista desplegable, casilla, opciones, aviso, migas de pan, paginación, tarjetas, pasos y preguntas frecuentes.
- **Organismos:** secciones completas de una página: cabecera, pie, portada, banda de llamado a la acción, formulario de contacto y tabla de niveles.
- **Plantillas:** la estructura de la página y el contenedor que centra el contenido.

Usa el interruptor de tema de la barra superior para ver todo en claro y en oscuro.
